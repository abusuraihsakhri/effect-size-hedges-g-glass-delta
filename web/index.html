Conventional magnitude

Effect signs preserve the direction of group 1 minus group 2. Magnitude thresholds are descriptive conventions, not clinical decision rules.

Cohen's d uses the sample-size-weighted pooled SD. Hedges' g applies J(df) ≈ 1 − 3/(4df − 1), where df = n1 + n2 − 2. Glass's delta uses group 2's SD. The SE is a large-sample approximation for Cohen's d, not a confidence interval or the SE of the other estimators.

Input requirements: both groups have at least two observations, values must be finite, and the control SD must be positive. These calculations assume independent groups.
